📦 Inventory Management App
📌 Overview
This mobile application is designed to efficiently manage inventory, sales, and customers. It provides user authentication, inventory tracking, sales recording, report generation, and data export features.

🚀 Features
🔐 User Authentication
Implement user login functionality.
📦 Inventory Management
Add new inventory items with name, description, quantity, and price.
Perform CRUD (Create, Read, Update, Delete) operations on inventory items.
Search inventory items by name or description.
Add new customers with name, address, and mobile number.
💰 Sales Management
Record sales with date, quantity, and payment method (Customer Name / Cash).
📊 Reports
📜 Sales Report – View and analyze sales data.
📦 Items Report – Get insights into inventory details.
🧾 Customer Ledger – Track all transactions related to a customer.
📂 Data Export
🖨 Print Reports
📊 Export to Excel
📄 Generate PDF Reports
📧 Send Reports via Email
🛠 Tech Stack
Framework: Flutter
State Management: GetX
Database: Firebase Firestore
Authentication: Firebase Auth
Tools: Git, GitHub, Postman, VS Code, Android Studio
